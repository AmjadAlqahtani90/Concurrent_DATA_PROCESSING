# Concurrent Data Processing

This project demonstrates concurrent data processing using **Java** and **Go**.

## Requirements

## How to Run

### Java Version

1. Open Terminal and navigate to the project directory:

   ```bash
   cd Concurrent_DATA_PROCESSING
   ```

2. Compile the Java files:

   ```bash
   javac Main.java TaskQueue.java Worker.java
   ```

3. Run the program:

   ```bash
   java Main
   ```

### Go Version

```bash
cd Go-Version
```

Run the Go program:

```bash
go run main.go
```
